# Protocole et chaine

Forks, halvings, mises a jour majeures, incidents reseau, changements
d'emission.

Domaine ou la date est connue a l'avance dans la moitie des cas. Une echeance
annoncee douze mois plus tot ne produit pas le meme mouvement qu'un incident.
Le champ `anticipation` de chaque fiche le note.

### halving-bitcoin-2024

- Date : 2024-04-19
- Categorie : protocole.changement_emission
- Portee : bitcoin
- Anticipation : totale, date calculable des annees a l'avance
- Statut : a_mesurer
- Source : a confirmer — verifier la hauteur de bloc et sa date

Division par deux de l'emission de bitcoin. Evenement le plus anticipe du
domaine : la mesure sert surtout a etablir qu'une echeance connue ne produit
pas de choc datable.

| Fenetre | Absolu | Relatif BTC |
|---------|--------|-------------|
| J+1     |        |             |
| J+7     |        |             |
| J+30    |        |             |

Trajectoire retenue : a mesurer. Mesurer aussi J-30 : si le mouvement precede
la date, l'evenement n'est pas le declencheur.
